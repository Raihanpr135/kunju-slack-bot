# Kunju Slack Bot

A simple Slack slash-command bot built with Node.js and Slack Bolt.

## Commands

- `/kunju-ping` — Checks bot response and latency
- `/kunju-help` — Shows available commands
- `/kunju-catfact` — Gives a random cat fact
- `/kunju-joke` — Gives a random joke

## Tech Stack

- Node.js
- Slack Bolt
- Axios
- Slack Socket Mode
